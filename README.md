# 麻雀オンライン（ネット対戦版）

サーバ権威型のオンライン4人打ちリーチ麻雀。既存の単体版(`../index.html`)の
**役/点数/シャンテン/CPU判定ロジックをサーバ側で再利用**し、各プレイヤーには
自分視点だけを配信します。

- **自動マッチング**：空いているCPU席のある卓に着席、無ければ新卓(1人+CPU3)を作り即開始
- **ルーム/フレンド対戦**：合言葉(4文字)で部屋を作り、友人が同じ合言葉で合流
- **席の切替**：切断→自動CPU化(名前保持) / ホストが席をCPU化 / CPU席へ後から参加
- 1人+CPU3 / 2人+CPU2 / 3人+CPU1 / 4人 — 参加人数に応じて自然に構成が変わる

## 構成
```
online/
  server/
    engine.js   … 既存ロジックを Node で読み込む(ブラウザAPIをスタブ)。役/点数/CPUを再利用
    table.js    … 1卓の進行(配牌→ツモ→打牌→反応→和了/流局→次局)。人間/CPU席・切替対応
    index.js    … WebSocket サーバ + 自動マッチング + 静的配信
    test-engine.js / test-table.js … 検証(判定・全CPU進行)
  public/
    index.html  … 対戦クライアント(盤面描画・操作)
    tiles.png   … 牌スプライト(単体版と共通)
```

## 起動
```bash
cd online
npm install          # ws
npm start            # http://localhost:8787 で起動(WebSocketも同ポート)
```
ブラウザで `http://localhost:8787/` を開く。複数人で遊ぶには全員が同じURLに接続
（LAN内なら `http://<サーバのIP>:8787/`、インターネット公開はホスティングが必要）。

## 検証
```bash
npm run test:engine  # 役/点数/シャンテン/CPU が正しく動くか
node server/test-table.js   # 全CPUで対局が最後まで進むか
```
